# Number Guessing Game in C

## About the Project
This is a simple console-based Number Guessing Game developed using the C programming language.

The player tries to guess a randomly generated secret number. The game provides hints to help the player identify the correct number.

## Features
- Random number generation
- Hints for guesses that are too high or too low
- Tracks the number of attempts
- Displays a success message when the correct number is guessed

## Concepts Used
- C Programming
- Loops
- Conditional Statements
- Random Number Generation
- Basic Problem-Solving

## Purpose
This project was created as a beginner-level programming project to practice logical thinking and strengthen my fundamentals in C.
